# V3.8 上传、地图与快捷发布验收

2026-10-05。本轮按“上传需求 → 地图定位 → 核对安排 → 点击发布 → 现场回执”调整叫应主工作台；不接入真实天气、大模型或 GPS。

## 已实现

- Excel / CSV 保留村庄、集合点原名，增加 WGS84 经度、纬度列。预览可集中编辑协助、轮椅与分组信息；未知信息不自动填零，只有用户明确点击批量补齐才采用通用条件。
- 在指挥台地图旁上传；尚未提交的坐标用橙色预览，采纳需求高亮。无位置、超出有限路网范围、距接入节点超过 500 米的需求继续列为待定位，不能虚构路径。
- “启用瑞安道路”将未执行的需求保留并切换至已有真实道路网络；已有发布、执行或无法映射记录时拒绝转换，不重置原记录。
- 待定位需求可以在地图选择候选道路点，确认后计算安排。独占待定位点保留原编号；多批共享点仅定位当前批，不擅自改变其他需求。
- 主工作台发布弹框无需姓名、指定文字或协调说明；保留一次点击确认、版本一致性、路网与容量检查。Guardian 同样取消姓名必填，默认记录“演练值守”，真实点击和确认令牌仍保留。
- 地图按车辆筛选路线；草案虚线、发布路线实线；根据现场回执更新待接、车上、到达与车辆登记位置。模拟运输播放可暂停、重置，不改变任务事实，不表示 GPS。
- 地图附近的雨情卡显示模拟最近 1 小时累计量、演练等级、来源与更新时间。20 / 50 / 80 mm 可切换；同级数值变化不反复重算，等级变化触发草案复核，不自动发布或封路。


覆盖：上传字段与原坐标保留、有限路网匹配、无定位及共享定位、整批原子提交、人数/容量/单向路约束、跨页面状态与持久化、版本冲突、原执行数据恢复、雨量口径、禁止自动批准、在线失败回落，以及离线缓存清单。

界面回归包含：人工编辑数值后立即点击提交也使用新值；刷新核对依据不丢手工定位和补值；轮椅人数未知或大于协助人数时不静默填零；选点绑定草稿版本，离开工作区取消选点；模拟播放不改人员台账。

## 浏览器实际操作

使用独立本地 Pages 预览（与用户原服务存档分开）和纯合成验收名单：

1. 保留 15 人初始需求启用道路，导入 2 人含坐标需求与 1 人无坐标需求；前者出现在地图，后者列入待定位。
2. 在地图补点后查看安排，点击发布弹框中“发布这批任务”，未输入姓名或确认文字；未安排人员继续显示原因。
3. 同浏览器另一页面选择车辆并确认接收，登记联系与上车；指挥地图同步显示“待接 1 · 车上 3”，车辆面板显示当前车上 3 人。
4. 播放运输演练，界面明确显示“非 GPS、时间压缩、不改变任务进度”；任务更新停止旧播放。
5. 启动雨情演练切到 50 mm，再切 80 mm，显示对应等级及“触发复核”；上传预览人工修改值保持。
6. 新上传 2 人名单，将协助人数从 0 改为 1 后直接点击导入，台账正确保留协助 1 人。
7. Guardian 完整研判输出 15/15、加权等待 168；操作人留空，实际点击人工确认后模拟发布成功并生成通知文本，默认身份为“演练值守”。

## 仍保留的边界

- 地图是已有瑞安局部道路快照（101 节点、138 路段），不覆盖瑞安全域；人员、车辆、接收用途、容量、速度与道路状态仍属演练设定。
- 现场回执位置不是实时 GPS；本轮未实现跨设备同步、真实天气自动接入、多趟运输或模型自主调度。
- Guardian 使用独立演练底数，不会将其中的发布结果写入主工作台；当前 API 入口仍在 `dist/guardian/agent/api-config.js`，默认离线。
- 雨情自动获取、过期校验、阈值事件和草案复核的后续方案见《V3.8 天气与运输联动设计》。推荐使用后端代理、密钥放 `.env`；本轮没有实现该转发服务。
