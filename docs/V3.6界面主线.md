# V3.6：用一条主线组织两个网页

主线：现场上报 → 指挥核实 → 确认转移安排 → 现场执行反馈 → 指挥核验到达。

| 角色 | 默认入口 | 做什么 | 下一步 |
|---|---|---|---|
| 现场 | 报情况 | 选择人数变化或道路险情，输入/语音整理，核对确认卡 | 提交后在上报记录看结果 |
| 指挥 | 核实情况 | 处理待核实、受阻、到达待核验事项 | 安排转移或跟踪完成 |
| 指挥 | 安排转移 | 查看地图、逐车安排和未安排原因，人工确认 | 现场接收任务 |
| 现场 | 我的任务 | 选择负责车辆，界面只突出当前可做的一步 | 接收、联系、上车、到达分别确认 |
| 指挥 | 跟踪完成 | 查看车辆状态，核验已到达人员 | 完成后复盘 |

## 页面如何减负

- 两端使用浅灰蓝背景、白色业务卡片、青绿色主按钮，深蓝只用于紧凑角色抬头。
- AI 对话固定在顶部，点击打开侧边对话框。未接入大模型的状态保持明确。
- 地图与方案只在“安排转移”展示；基线、约束与变更明细可以展开。
- 人员资源、天气播报、公开依据、复盘、情景切换、评估和备份收进“更多资料”。
- 执行页优先显示到达待核验人员。指挥台代登记现场操作收进演示工具。
- 切换页面保留草稿和确认卡版本；新事实同步后，过期确认卡仍须重新核对。
- 展开的辅助内容在两端同步刷新时保持展开，减少填写被打断。
