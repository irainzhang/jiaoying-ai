## 建议冻结的一条演示

空白开场 → 上传20人并看人数算式 → 发布能安排的部分并展示缺口 → 一车独立接令发车 → 现场整批补报3人 → 指挥核实后总数23 → 根据容量准备下一趟 → 结束并查看仍未完成事项。

这条演示不用把所有菜单点一遍。地图展示当前安排与回执、雨量继续模拟、守护助手解释本场数据；讲清哪里需要人确认。不能预设“23人必定全部解决”，实际结果要由冻结版资源和路网计算。
