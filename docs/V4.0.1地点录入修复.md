# V4.0.1 地点录入修复

2026-10-05。旧版使用有限已登记村庄目录校验口述地点，因此“玉海街道，新增10人”虽然已经成为正确文字，却在后续规则匹配时被整条拒绝。它不是麦克风识别失败，也不是大模型给出了错误答案；当前未接入大模型。

## 新操作

1. 默认使用“选地点填人数”：地区和具体接人点均可下拉查看、按名称/编号搜索，也可直接填写新名称，然后填人数。
2. “语音 / 文字”可以先选地区，再只说新增人数；也可以直接说完整地点与人数。未登记地区保留原名和人数，生成可修改的需求行。
3. “导入名单”继续支持 Excel / CSV，预览里的地点也改为相同搜索选择器。
4. 一张核对表补地点、人数与已知协助情况，再保存。地点未明确可先保存为待定位；不会把一个街道当作具体集合点，也不按相似名称编造坐标。

选择地区后，接人点列表仅列出该地区的登记点；换地区会清除旧接人点和坐标。明确选中同名地点的编号时保留唯一编号。键盘可用上下键和 Enter，Tab 提交手填文字，Esc 关闭候选。

## 回归范围

- 用户原话“玉海街道，新增10人”应保留 1 条、10 人、待定位。
- 未给地区时保留人数并提示补地区；多个新地区分别保留。人数歧义、否定、估计及非法数量仍要求核对。
- 地区与接人点联动、原值保留、同名编号明确选择、未确认人数不自动填0。
- 快捷表单只生成预览，不自动提交；改人数后旧预览失效，保存仍校验当前任务版本。
- 自动化覆盖筛选、输入法、键盘、失焦、候选浮层清理，以及真实控制器导入后的需求守恒。

界面候选来自当前任务已登记目录，不是完整瑞安行政区划或联网地图搜索。新地名需由人补具体位置；真实地理编码和大模型仍未接通。
