# V4.3 操作与验证

更新：2026-10-06。本轮升级本地程序与 Pages 构建内容，未将 GitHub Pages 变成在线共享服务。DeepSeek 密钥仍只由后端读取。

## 从哪里操作

| 目的 | 入口 | 操作顺序 |
|---|---|---|
| 录入人员需求 | 指挥工作台 → 01 需求录入 | 选地点、Excel 或语音/文字 → 整理 → 核对人数和位置 → 保存 → 到任务执行发布 |
| 新增或更新资源 | 顶部「资源录入 / 管理」 | 选工作人员/车辆/接收点 → Excel 或语音 → 核对变更 → 加入草稿 → 保存资源并重新计算 |
| 执行中增援 | 同一个资源管理入口 | 增加人员与车辆，或调整尚未出发车辆的编组 → 保存 → 核对受影响的安排再发布 |
| 找到模型能力 | 顶部「AI 录入 / 帮助」 | 进入需求、资源或现场补报的语义整理入口；展开下方操作帮助可使用本地导览 |
| 查看识别和修改记录 | 03 任务记录 → 录入来源与人工修改 | 查看原话、模型字段、本地整理字段、最终确认字段，以及修改前后差异 |
| 两端协同 | 双击项目根目录「启动同WiFi协同.cmd」 | 本机打开指挥专用加入链接 →「邀请现场人员」→ 绑定车辆和人员编号 → 手机打开现场邀请 |

资源 Excel 模板增加了可选的「操作」列：新增、修改、停用、恢复。不填时按新增处理；修改已有资源需填写编号，只填写要更新的字段，其余字段保留。语音可说「工作人员 D01 今天未到岗」「把 V2 总核载改成 19 人」「恢复 S1 接收点」。不确定的字段会留待核对。

车辆总核载包含司机和随车人员，乘客容量会扣除这些名额。已出发车辆的型号、核载、编组和起点不能在途中重写；已有乘员、到达占用与执行记录保留。若停用当前资源或调整未出发车辆，旧安排会失效或阻断，需要指挥台核对更新。增援不代表系统自动发布。

历史任务如果缺少总核载和人员编号，不能自动推算为新版资源库。在这种旧任务中，资源窗口会解释只读原因；结束并保留旧任务记录后，新建任务可登记完整资源。程序不会为升级自动结束当前任务。

## 本轮修复与边界

- 明确说「接人点不确定」「接人点不在那里」时，会清空原接人点；地区仍可保留。省略地点与明确否定地点分别处理。
- 人数、编号、到岗状态等关键值需要原话依据；口头更正、总人数与新增人数分别处理。证据冲突时保留待补项，不能通过批量默认值绕过核对。这是保守校验，不是对任意自然语言的正确性保证。
- 资源更新先展示修改前后，再加入表单草稿。最终保存时记录人工修改后的实际字段。识别结果本身不会写入正式业务数据。
- 局域网现场身份绑定车辆与人员编号。服务端限制可读数据与可提交动作，现场不能发布、改资源、结束整场任务或操作其他车辆；身份撤销、编组变化或新建任务后需要重新加入。
- 地图位置来自人工回执，显示最近回执时间；超过 10 分钟提示核对，不宣称 GPS 实时定位。
- DeepSeek 用于需求、资源和新增人员补报的语义理解；语音转文字仍由浏览器服务提供。执行回执规则、路径与资源计算、操作帮助不是大模型结果。调用失败会标注本地回落。
- 来源记录随保存、完整导出及任务归档保留。它记录系统收到并经人工核对的内容，不是第三方签名的模型调用证明；历史旧记录不会补造来源。

## 已执行验证

自动化回归命令：`node --test tests/*.test.cjs tests/*.test.mjs`。最终结果 **785/785 通过，0 失败**；完整日志保存在本地 `tmp/v43-final-tests.log`，覆盖语义证据校验、保存回滚、资源增援、历史方案验证、局域网角色权限和已有工作流程。

真实 DeepSeek 接口用 6 条合成例句验证通过：中文人数、口头更正、未知接人点、工作人员离岗、车辆总核载、多地区拆分。观察耗时约 0.68—1.50 秒，仅代表这些样例；不作为语音准确率或减灾收益。记录位于本地 `tmp/v43-live-semantics.json`，不包含密钥。

浏览器验证使用独立的合成任务：

1. 识别「玉海街道新增三人，接人点不确定，其中一人需协助，无轮椅，可以分组」，得到 3 人、1 人协助、0 轮椅、接人点留空。
2. 人工将 3 人改为 4 人并保存，记录显示「3 → 4」，刷新后仍可查看原话与修改记录。
3. 指挥身份生成 V1 / D01 的现场邀请；现场页面只呈现本车任务。现场确认收到任务后，指挥台即时显示对应编号及回执。
4. 工作人员 D01 离岗的语义结果更新已有记录，预览呈现到岗「是 → 否」，保留原岗位与编号。

Pages 构建通过，生成 120 个静态发布文件；本轮未提交或部署到 GitHub。发布包与待交付代码的密钥隔离检查通过（383 个文件，0 处命中真实密钥）；`.env` 仍被 Git 忽略。本机服务已重启，原任务身份、revision、方案和人员阶段对比一致。

## 仍需团队真机验收

额外验证：同一浏览器其他标签切换身份、任务 revision 不变时，旧页重新读取当前权限并清除旧身份内存草稿；迟到的轮询、SSE、提交与语义结果不能回写到新身份。

同一 Wi-Fi 下用实际手机执行：打开邀请 → 接令 → 批量登记已联系 → 发车 → 上车 → 到达；核对电脑即时收到。再测试断网重连、撤销邀请，以及语音中的方言、噪声、重复与更正。

本轮双身份网页联动已验证，但不是两台实体设备或真实麦克风测试。手机通过 HTTP 局域网地址打开时，浏览器可能禁用麦克风；可先用系统键盘听写或 Excel，正式麦克风部署需可信 HTTPS。

彩云实况、GPS、正式公网共享、完整瑞安地址检索，以及真实灾情效果评估仍未完成。当前雨量、人员、容量与行驶时间仍为演练设定。
