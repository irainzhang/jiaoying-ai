# V4.0.2 瑞安地点目录来源与使用范围

瑞安地图模式现在使用 `dist/assets/maps/ruian-places.json`，不再把“演示村 A / B / C”当成瑞安真实村庄目录。该目录可以离线加载，选择与搜索不调用外部地理编码服务。

## 当前收录内容

| 类别 | 数量 | 来源和用途 |
| --- | ---: | --- |
| 街道 | 8 | 玉海、安阳、锦湖、东山、上望、莘塍、汀田、飞云；名称来自已有 OSM 快照，并用瑞安市政府公开文件辅助核对 |

| 城区道路点 | 10 | 现有路网中的 3 个具名道路交叉口和 7 个具名道路位置；坐标来自真实 OSM 节点，可以匹配演练路网 |

另有一个“瑞安市城区道路”公共候选组，用来组织道路位置。它不是行政街道，目录也不是瑞安市全量村社、避难场所或实时地址库。

## 坐标与归属规则

- 3 个交叉口要求具名道路在原始 OSM 数据中共享同一个节点，不能仅凭地图线条相交推断通车连接。
- 7 个道路位置的名称形如“瑞湖路（片区北侧道路点）”。“片区北侧”是当前有限路网内的相对位置说明，不是官方 POI 名称、整条道路端点或门牌。
- 道路候选的经纬度与现有路网节点完全一致，并保留 `nodeId`、`osmNodeId`、关联道路来源。它们不复用 `H1` 等合成业务点，也不会把“演练集合点”改个真地名便冒充真实设施。
- 本地资料没有行政边界，不能用“离哪个街道标注点近”来认定所属街道。因此道路点标记 `administrativeAffiliation: unverified`，作为“城区道路候选·辖属待核”供人工选择。选择一个街道或社区，不应把某一道路点自动当作其村委会或官方接人点。
- 社区记录只提供名称、来源、表列上级街道，**没有坐标时就保留待定位**。街道中心点只用于地图地名参考，不能作为接人坐标。
- 公园保留原始多边形；未核实入口和停车条件，不取面中心或顶点假装车辆入口。
- 人员、车辆、容量、道路开放与通行速度仍是演练设定。真实地点名称不代表现场可通行或已被批准作为集合点。

## 复现和扩充

运行 `python scripts/build-place-directory.py`，使用三个已检入的本地地图文件重建目录；不联网、不使用密钥。JSON 的 `provenance.inputSha256` 记录输入文件摘要。自动测试会检查道路名称与共享节点、坐标一致性、来源链接及非虚构行政归属。

后续若取得团队确认的村社名单、村委会/接人点 WGS84 坐标与有效街道归属，可增加对应记录并记录资料来源。提供真实名单前，不补造门牌、村委会、官方避难点或坐标。已有任务和历史需求须保持原始名称及来源；新目录用于新选择，不应静默改写旧任务事实。
