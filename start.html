指挥台沿着三步主线处理任务；现场端专注执行与补报。安排、进度和结束按钮集中在同一个执行页面。

同一浏览器打开两个标签页，即可演示即时联动。公开版各设备的数据独立；同 Wi-Fi 协作请在电脑运行 node lan-server.mjs，双方使用终端给出的同一房间链接。

如果仍看到旧版布局，可打开 保留记录，更新到最新版。

01

需求录入

上传 Excel / CSV 名单，或语音说明一批需求；在这里集中核实、补充位置与协助信息。未知项保留待补，不默认填零。

02

任务执行

在同一处看地图、配置资源、点击发布。每车接令和联系后独立发车，送达后可再排一趟。完成演练后点击「结束当前任务」，提前结束也保留未完成事项。

03

任务记录

查看本场结果、历史任务与复盘报告，导出留档。「开始新任务」保存旧场记录，默认从0人开始；可选15人示例，或明确结转上一场仍待接需求。

这一版的 AI 与天气状态

主台名单与口述使用本地规则整理，路线和资源分配由算法实际计算。「城市韧性守护」可读取本场需求、计算草案并回到主台核对发布；独立算法沙盘与 API 接口说明保留在次级入口。大模型、在线 Agent 与彩云实况未接通。雨量保持模拟；浏览器语音识别可能联网，不保存录音。

结束与保存

结束后两端只读，不会把未完成人员自动标成完成。历史最多 10 场、合计 4 MB，满额阻止新建且不自动删除；导出后可明确选择清理某场历史，绝不自动删除。需要保留的记录请导出 JSON。
